**✈️ Airfare Insights – Indian Flight Price Analysis & Trend Discovery**

Airfare pricing in India changes dynamically based on multiple factors such as airline brand, travel duration, number of stops, route demand, and departure timing.
This project analyzes Indian domestic flight ticket data to uncover pricing patterns, travel trends, and fare variations across different airlines and routes.

Using Python, SQL, and data visualization techniques, the project explores how travel-related attributes influence airfare prices and customer booking behavior.

The primary goal of this project is to generate actionable insights that can help travelers make informed booking decisions and support data-driven analysis in the aviation industry.


**🎯 Objectives:**
- Analyze factors affecting airline ticket prices
- Compare airfare trends across airlines and routes
- study the impact of stops and duration on pricing
- Generate insights using SQL and statistical analysis
- Visualize travel and pricing patterns effectively
- Understand customer travel behavior and market trends

**📂 Dataset Information:**
- Airline name
- Source city
- Destination city
- Departure time
- Arrival time
- Flight duration
- Number of stops
- Ticket price
- Travel class
- Journey date


**🛠️ Technologies & Tools Used:**
1. Programming - Python
2. Data Analysis - Pandas, NumPy
3. Visualization - Matplotlib, Seaborn, Plotly, Power BI
4. Database - SQL
5. Statistical Analysis - SciPy
6. Development Environment - Jupyter Notebook


**🧹 Data Cleaning & Preprocessing:**

The following preprocessing tasks were performed:

i. Checked and handled missing values
ii. Removed duplicate records
iii. Converted duration and time formats
iv. Standardized column names and data types
v. Validated pricing and route consistency
vi. Prepared dataset for analysis and dashboard visualization


**📊 Exploratory Data Analysis (EDA)**

The project includes detailed exploratory analysis to identify airfare patterns and travel behavior:

Distribution of flight ticket prices
Airline-wise average fare comparison
Route-based pricing analysis
Impact of stops on ticket price
Duration vs airfare relationship
Departure timing trends
Outlier and anomaly detection

---

**📌 Key Insights**
- Flights with fewer stops generally have higher ticket prices
- Certain airlines consistently maintain premium pricing
- Longer travel durations often correlate with increased airfare
- Peak travel timings influence fare fluctuations significantly
- Major metro routes show higher average ticket prices
- Airline pricing strategies vary across travel classes and routes
